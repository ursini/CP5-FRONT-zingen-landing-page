# Zingen — Landing Page de Produto

Landing page desenvolvida como Atividade Prática de HTML e CSS, com foco principal em responsividade e adaptação de layout para diferentes tamanhos de tela (desktop, tablet e mobile).

## 🚀 Tecnologias Utilizadas

* HTML5 (com tags semânticas)
* CSS3 (utilizando Flexbox, Grid Layout e Variáveis CSS)
* Responsividade via Media Queries

## 📱 Funcionalidades

* Layout moderno em Dark Mode inspirado no design de referência.
* Seção Hero com chamadas para ação (CTA).
* Grelha de funcionalidades interativa com os diferenciais do aplicativo.
* Tabela de preços e planos (Básico, Premium e Família).
* Rodapé estruturado com links úteis e redes sociais.
